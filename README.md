# Lumine Arkos System

Una aplicación de broma hecha con Pygame que simula la instalación de un virus en el ordenador. 🖥️

Está pensada para hacer bromas a amigos, familiares, etc. La aplicación muestra una instalación falsa con una terminal, procesos de instalación, códigos de memoria y, finalmente, un supuesto error del sistema seguido de una recuperación de Windows.

**No instala ningún virus ni modifica realmente el ordenador.** Todo lo que aparece en pantalla es una simulación.

### 🚨 Salida de emergencia

Si necesitas cerrar la aplicación durante la simulación, pulsa **Subir volumen (+)**.

La tecla **ENTER** también permite salir cuando aparece la pantalla final de recuperación.
